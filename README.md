## 🖥️ Ver el sitio en local

Opción 1: abre `index.html` directamente en tu navegador.

Opción 2: en VS Code, con la extensión **Live Server**, clic derecho sobre
`index.html` → **Open with Live Server**.

## ▲ Despliegue en Vercel

1. En [vercel.com](https://vercel.com) → **Sign Up** → *Continue with GitHub* → plan **Hobby** (gratis).
2. Dashboard → **Add New... → Project** → importa el repositorio `Portafolio-vercel` → **Deploy** ⚡
3. Vercel detecta automáticamente que es un sitio estático (HTML/CSS).
4. Comparte tu URL pública, del estilo `https://portafolio-vercel-xxxx.vercel.app`.

## 🔄 Flujo de actualización

Edita los archivos en VS Code → *Commit* → **Sync Changes**.
Vercel redespliega automáticamente en segundos; la URL no cambia.
